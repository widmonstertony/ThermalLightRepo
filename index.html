Installation

  1. Add the source URL to Sileo or Zebra.
  2. Refresh sources.
  3. Search for the package name and install it.
  4. Follow the package-specific restart instructions shown by your package manager.

ThermalLightControl 3.5.2

Prevents thermal brightness caps on iPadOS 16 while preserving CPU/GPU throttling, temperature monitoring, warnings, watchdog, and emergency shutdown.

Safety: sustained high brightness at elevated temperatures increases power consumption, display wear, and overheating risk. Monitor device temperature and disable the tweak if the device becomes unusually hot.

VirtualMac Audio Stability Fix 1.0.1

Preserves VirtualMac microphone and speaker support while preventing the iPadOS 16.1 MediaExperience/Now Playing teardown race.

Virtual Mac 1.2.3+609.pause2

Modified upstream build with native in-memory Pause/Resume controls and an automatic capability refresh after the virtual machine starts.

Compatibility: M1/M2 iPads running iPadOS 14.5–16.3.1 only. This package does not support iPadOS 16.4 or later.

NewT66y 2.3.7 Local Package Builder

This repository does not host or redistribute the NewT66y IPA, app bundle, icon, or a package containing the app. The open-source builder lets a user provide a lawfully obtained 1024app_ios_2.3.7.ipa on their own Mac and create a rootless .deb for local installation on their own device.

Important: the generated package is not available from this APT source. It must remain local and be transferred to the user's own device.
