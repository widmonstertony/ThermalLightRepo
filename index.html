Installation

  1. Add the source URL to Sileo or Zebra.
  2. Refresh sources.
  3. Search for ThermalLightControl and install it.
  4. Start the jailbreak environment again or perform a userspace reboot once.

Safety: sustained high brightness at elevated temperatures increases power consumption, display wear, and overheating risk. The tweak preserves CPU/GPU throttling, temperature monitoring, warnings, watchdog, and emergency shutdown. Disable it if the device becomes unusually hot.
