Virtual Mac 1.2.3+609.pause2

A modified build of the upstream Virtual Mac on iPad project with native in-memory Pause and Resume controls. The menu now refreshes after VM startup so Pause becomes available when the virtualization framework reports that the running VM can be paused.

Compatibility

Requires an upstream-compatible M1 or M2 iPad running iPadOS 14.5–16.3.1 with a supported rootless jailbreak. It intentionally cannot install on iPadOS 16.4 or later.

Before installing: save your work and completely shut down Virtual Mac. Pause keeps VM state only in memory; it is not a disk snapshot and cannot survive jetsam termination, userspace reboot, or device restart.

Source and license

Based on the MIT-licensed Virtual Mac on iPad project. The corresponding pause/resume source patch and upstream MIT license are included in Tony Repo.
