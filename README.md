# Tony Repo

Personal APT repository by widmonstertony for rootless jailbreak tweaks.

Repository URL:

```text
https://widmonstertony.github.io/TonyRepo/
```

Add the URL to Sileo or Zebra and refresh sources. The first available package is
**ThermalLightControl** for iPadOS 16 rootless jailbreaks; more packages can be
published here later.

> Sustained high brightness at elevated temperatures increases power consumption,
> display wear, and overheating risk. ThermalLightControl preserves CPU/GPU throttling,
> temperature monitoring, warnings, watchdog, and emergency shutdown, but users should
> still monitor device temperature and disable the tweak if the device becomes unusually hot.
